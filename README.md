# Naxos Frontend Challenge

## Intro

Inizierei con la creazione dell'interfaccia utente per poi aggiungere la logica di gestione dello stato ed infine suddividere l'app in componenti. opto per una visualizazzione a card (per una maggiore chiarezza). Dato il numero elevato di post presenti ho implementerei la ricerca dei post 


## Processo

Dopo aver seguito gli step pianificati, ho optato per uno stile moderno ed intuitivo evitando di inserire elementi di UI che in questa prima fase risulterebbero superflui. In seguito la logica per ottenere i post da visualizzare i post e per aggiungerne di nuovi tramite form.
In ultimo correzzioni di eventuali sbavature UI o errori nella logica.

## Stack

- pnpm: packet manager robusto e sicuro, in grado di prevenire attacchi informatici di tipo supply chain.

- React: framework che consente autonomia nel lavoro e per la praticità dei componenti riutilizzabili ( a favore della scalabilità).

- Vite: include l'hot reload. le modifiche ai file React e CSS vengono applicate
automaticamente nel browser senza riavviare manualmente il server.

- CSS Vanilla: leggero e ampiamente supportato da tutti im maggiori browser. Non richiede librerie aggiuntive che rischierebbero di rallentare le performance dell'app.
- zustand: libreria leggera che richiede poco codice e permette di incentrare lo stato intuitivamente





## Avvio in sviluppo

Installa le dipendenze e avvia il server Vite:

```bash
pnpm install
pnpm dev
```
